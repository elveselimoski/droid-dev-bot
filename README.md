## Installation
- Manually:

Install it manually using custom repository
  <kbd>Settings/Preferences</kbd> > <kbd>Plugins</kbd> > <kbd>⚙️</kbd> > <kbd>Manage plugin repositories</kbd> and add https://elveselimoski.github.io/droid-dev-bot/updatePlugins.xml. After that you can search for `droid-dev-bot` in the marketplace plugins.
